# Code of Conduct

This project is focused on professional, respectful, and constructive collaboration in software development — including issues, pull requests, code reviews, design discussions, CI feedback, and commits.

Expected behavior
- Focus feedback on code and behavior, not on the author. Describe the problem, rationale, and suggest concrete fixes when possible.
- Be timely and responsive: acknowledge bugs, tag reviewers, and update PRs with requested changes.
- Use inclusive, clear language. Avoid profanity, sarcasm, or derogatory remarks.
- Give credit where due and be open to differing technical opinions.

Unacceptable behavior
- Personal attacks, hateful or discriminatory language, doxxing, or threats.
- Public shaming, hostile review comments, or demeaning messages.
- Posting sensitive information (credentials, private data) in issues, PRs, or discussions.

Reporting and enforcement
- Report violations to the maintainers at maintainers@example.com (or security@example.com for vulnerabilities). Reports will be handled confidentially.
- Maintainers may remove content, request edits, suspend contributions, or ban accounts for serious or repeated violations. Retaliation against reporters will not be tolerated.

Scope
- This policy applies to all project spaces: repository issues, pull requests, code comments, chat channels, and community forums.

This Code of Conduct is adapted for a software development workflow and complements repository policies and contributor guidelines.
